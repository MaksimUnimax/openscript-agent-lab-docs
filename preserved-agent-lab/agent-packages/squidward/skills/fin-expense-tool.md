# Fin инструмент

Эта инструкция описывает использование `fin.expense_add` как агентского инструмента.
Инструмент доступен только если у агента есть явное разрешение в `tools.json`.

## Правила использования

- Записывай расход только по явному запросу пользователя.
- Обязательные поля: `amount`, `product`.
- `category` не обязателен. Если категория не указана, используй `Без категории`.
- `description` не обязателен и используется только как комментарий.
- `currency` по умолчанию `RUB`.
- `occurred_at` можно не передавать, тогда сервер подставит текущее время.
- `payment_source` не обязателен.
- Не выдумывай расход, сумму, товар или категорию.
- Не используй SQL и не обращайся к базе напрямую.
- Не обходи allowlist. Skill сам по себе доступ не выдаёт.
- После изменения source package может понадобиться отдельное применение в Hermes runtime.
