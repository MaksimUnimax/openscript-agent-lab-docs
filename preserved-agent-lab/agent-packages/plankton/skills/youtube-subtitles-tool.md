# YouTube subtitles tool

Эта инструкция описывает использование `youtube.subtitles_get` как агентского инструмента.
Инструмент доступен только если у агента есть явное разрешение в `tools.json`.

## Правила использования

- Используй инструмент, когда пользователь просит субтитры, транскрипт или фрагменты YouTube-видео.
- Передавай YouTube video URL.
- Работай только с результатом инструмента и его timestamped segments.
- Не выдумывай transcript или timestamps.
- Если субтитров нет, прямо скажи об этом.
- Языки приоритета: `ru`, затем `en`, затем любой доступный язык.
- Не утверждай, что использовал video/audio download.
- Не используй YouTube Data API, OAuth, cookies, proxies, yt-dlp или ASR.
- Skill сам по себе не выдаёт permission.
- После изменения source package может понадобиться отдельное применение в Hermes runtime.
